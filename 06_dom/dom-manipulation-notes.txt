NOTES: DOM MANIPULATION - "chai aur code" EXAMPLE
====================================================

OVERVIEW
--------
This code demonstrates DOM MANIPULATION - creating an HTML element
entirely through JavaScript and inserting it into the page.


LINE-BY-LINE BREAKDOWN
-----------------------

1. CREATING AN ELEMENT
   const div = document.createElement('div')

   - Creates a new <div> element in memory (not yet visible on the page).
   - At this point it exists only as a JavaScript object - it is not
     part of the DOM tree yet.


2. LOGGING THE ELEMENT
   console.log(div)

   - Prints the div to the console. Since it hasn't been styled/filled
     yet, it'll show as an empty <div></div>.
   - Useful for debugging - you can inspect the element's current state
     at any point.


3. SETTING A CLASS
   div.className = "main"

   - Adds a CSS class "main" to the div (equivalent to class="main"
     in HTML).
   - Note: className sets/overwrites the whole class string. For
     adding/removing individual classes without overwriting others,
     classList.add() / classList.remove() is usually preferred.


4. SETTING AN ID DYNAMICALLY
   div.id = Math.round(Math.random()*10 + 1)

   - Math.random() generates a decimal between 0 and 1 (exclusive of 1).
   - Multiplying by 10 gives a range of 0-10, adding 1 shifts it to 1-11.
   - Math.round() rounds to the nearest integer.
   - Result: a random-ish integer ID between 1 and 11, assigned as the
     element's id.
   - WARNING: IDs are supposed to be unique per page. Random IDs like
     this could collide if this code runs more than once.


5. SETTING A CUSTOM ATTRIBUTE
   div.setAttribute("title", "generated title")

   - setAttribute(name, value) is the generic way to set ANY HTML
     attribute (standard or custom).
   - Here it sets the title attribute, which shows as a tooltip when
     you hover over the element.


6. INLINE STYLING
   div.style.backgroundColor = "green"
   div.style.padding = "12px"

   - element.style lets you set CSS properties directly via JS.
   - CSS properties with hyphens (like background-color) become
     camelCase in JS (backgroundColor).
   - This is equivalent to inline style="background-color: green;
     padding: 12px;"


7. ADDING TEXT - TWO APPROACHES COMPARED
   // div.innerText = "chai aur code"   <- commented out
   const addText = document.createTextNode("chai aur code")
   div.appendChild(addText)

   - innerText (commented out): a simple, direct way to set visible
     text. Easy but less "pure DOM" - it also triggers reflow/style
     calculations since it's aware of rendered styles.
   - createTextNode() + appendChild(): creates an actual Text node in
     the DOM tree and manually attaches it as a child of the div.
     This is the more "vanilla DOM API" way of doing it, and is what
     frameworks/libraries often do under the hood.
   - Both achieve the same visual result here, but the code shows the
     manual/explicit way intentionally (for learning purposes).


8. ATTACHING TO THE PAGE
   document.body.appendChild(div)

   - Until this line, the div existed only in memory - it wasn't visible.
   - appendChild() inserts the div as the last child of <body>, which
     is what finally makes it appear on the page.


KEY CONCEPTS SUMMARY
---------------------
Concept                  | Method/Property used
--------------------------|--------------------------------
Create element            | document.createElement()
Set class                 | element.className
Set id                    | element.id
Set generic attribute     | element.setAttribute()
Inline CSS                | element.style.propertyName
Create text node          | document.createTextNode()
Insert into DOM           | element.appendChild()


TAKEAWAY
--------
This snippet walks through the full lifecycle of dynamically building
a DOM element from scratch: CREATE -> CONFIGURE (class, id, attributes,
styles) -> ADD CONTENT -> ATTACH TO THE DOCUMENT. It's a good exercise
for understanding what happens "under the hood" when frameworks like
React render elements to the actual DOM.
